# AI智能助手 - 使用指南

## 🚀 快速开始

### 1. 启动应用
运行以下命令启动应用：
```bash
flutter run
```

### 2. 页面导航
应用包含以下主要页面：

#### 欢迎页面
- 应用首次启动时显示
- 展示主要功能特色
- 提供登录/注册入口
- 可选择跳过登录直接体验

#### 登录页面
- 现代化深色主题设计
- 支持邮箱/密码登录
- 记住登录状态选项
- 忘记密码功能
- 社交登录选项（手机号、生物识别）

#### 注册页面
- 分步骤表单验证
- 实时密码强度检测
- 用户协议确认
- 动画过渡效果

#### 首页
- 社保计算功能
- 养老金计算功能
- AI助手快速入口
- 设置页面入口

#### AI聊天页面
- 仿真聊天界面
- 智能问答功能
- 打字指示器
- 消息历史记录

#### 设置页面
- 账户管理
- 应用偏好设置
- 帮助与支持
- 安全退出

## 🔧 功能使用

### AI对话功能
1. 点击首页底部的AI助手按钮
2. 在弹出的对话框中点击"开始对话"
3. 进入AI聊天页面
4. 输入问题并发送
5. AI会智能回复相关建议

### 社保计算
1. 在首页选择"社保计算"标签
2. 填写相关信息（工资、地区等）
3. 点击计算按钮
4. 查看计算结果

### 养老金计算
1. 在首页选择"养老金计算"标签
2. 输入缴费年限、缴费基数等信息
3. 系统自动计算预估养老金
4. 查看详细计算报告

### 个人设置
1. 点击底部导航的设置按钮
2. 管理个人信息
3. 调整应用偏好
4. 查看帮助文档

## 📱 操作技巧

### 快捷操作
- **长按AI按钮**: 快速访问常用功能
- **左右滑动**: 在计算页面间切换

## 🆘 常见问题

### Q: 忘记密码怎么办？
A: 在登录页面点击"忘记密码"，通过邮箱重置密码。

### Q: AI回复不准确怎么办？
A: AI正在持续学习中，可以通过设置页面提供反馈帮助改进。

### Q: 如何切换主题？
A: 目前支持深色主题，后续版本将支持主题切换功能。

### Q: 数据如何同步？
A: 登录后数据会自动同步到云端，确保多设备数据一致。

### Q: 如何联系客服？
A: 在设置页面的"意见反馈"中可以联系我们。
